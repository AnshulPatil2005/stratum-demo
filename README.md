# stratum-demo

A tiny shop library, used to show [Stratum Open](https://github.com/AnshulPatil2005/stratum-open) reviewing a pull request.

Its pull requests contain planted problems on purpose. Every key in them is a random fake, and every package that isn't on PyPI was made up for the demo. Don't install from this repository.

Setup is two files: [`.github/workflows/stratum.yml`](.github/workflows/stratum.yml) and [`.stratum/policy.yml`](.stratum/policy.yml).
